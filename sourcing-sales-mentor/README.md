# Sourcing Sales Mentor · 外贸销冠导师提示词

> 一份约 1.2 万字的系统提示词（System Prompt），把通用大模型变成一位能带人做 B2B 外贸采购服务的销冠导师 + 业务分身。
>
> **一句话概括**：不是让 AI "聊外贸"，而是让 AI 按五个固定工作模式、带着业务档案和避坑清单，产出当天就能执行的动作。
>
> 本项目经过**两轮独立对抗审查共 28 项修订**（详见第 6 节）——提示词工程和写代码一样，需要 review、测试和迭代，而不是一次写完。

## 1. 为什么做这个

通用大模型回答外贸问题，有三个稳定缺陷：

1. **答案太"正确"** —— "要重视客户信任"、"注意质量控制"、"做好供应链管理"。听着都对，但不说周一早上该干什么。
2. **每次都从零开始** —— 你说过十遍的业务背景（客单价、市场、团队规模），第十一遍它还是不知道，还是给你通用建议。
3. **不做决定** —— 问"这个单要不要接"，它给你五个角度，最后一句"最终看你自己"。

这三个问题不是模型能力问题，是**提示词结构问题**。要解决的不是"下次问得好一点"，而是把**工作方式**写进系统提示词。

---

## 2. 三个关键设计决策

### 决策一：从「文案型模板」改成「工作助手型结构」

大多数流传的提示词模板是为"写内容"设计的：角色 → 背景 → 任务 → 风格 → 受众 → 输出格式。这套结构能产出漂亮的文案，但撑不起一个工作助手。

工作助手需要的是另外四样东西：**模式（不同任务走不同流程）、判据（什么算好、什么算不合格）、动作（具体做什么）、约束（什么不能做）**。

所以在这个项目里砍掉了「创始人 IP 信息」「行业热点」「参考短语钩子」这类文案字段，换成「业务档案槽位」和「模式切换系统」。字段不是越多越好，是**越贴合工作方式越好**。

### 决策二：五模式切换，而不是一个万能大 prompt

一个"什么都能干"的提示词，结果通常是什么都干得浅。所以把它拆成五个模式，用指令切换：

| 指令 | 模式 | 解决什么 |
|---|---|---|
| `/导师` | 销冠导师 | 遇到具体难题，要诊断 + 方案 + 下一步规划 |
| `/流程` | 全流程导航 | 走到某个环节，要知道标准动作 + 该避的坑 |
| `/优化` | 每日优化 | 把今天的工作清单丢进来，AI 分工：它做哪些、你做哪些、哪些别做 |
| `/信任` | 信任建设 | 无产品/无工厂的服务型公司，怎么解决客户"不敢下单" |
| `/机会` | 10 倍机会雷达 | 找当下最高杠杆的增长点，并明确该砍掉什么 |

不输指令时，AI 按固定优先级判断属于哪个模式，并标注【当前模式：XX】。判断规则里专门区分了"**算**"（核算问题 → `/流程`）和"**决策**"（要不要接 → `/导师`）——这是对抗审查发现的典型误路由：带金额的问题不等于自动变成核算问题。

### 决策三：分身靠档案，不靠形容词

写"你是一位资深外贸专家"没有用，模型会演一个泛泛的专家。真正让它像某个具体的人的，是**参数和约束**：

- 他的业务模式（有产品还是无产品？收服务费还是赚价差？）
- 他的能力缺口（不会英语？没有团队？不懂认证？）
- 他的硬约束（预算多少？每天能投入几小时？时区在哪？）
- 他的阶段（0 客户冷启动 / 有稳定返单）

所以提示词里有一节叫**业务档案**，全部是可填槽位。空着的时候，AI 必须显式说"这里我基于假设"，不许假装知道——这一条比任何"你要严谨"的要求都有效。

## 3. 结构总览

一份 12 节的提示词，骨架如下：

```
使用指令表（含自动模式判断优先级：核算 vs 决策拆分）
一、角色（导师 + 分身双身份；禁止编造履历与第一人称虚构经历）
二、背景（业务画像 + 核心矛盾）
三、业务档案（可填槽位：团队/阶段/语言/货源/收款/获客策略+证伪出口）
四、五大工作模式（每个模式带合格线、失败信号、固定工作流程与输出格式）
五、风格与语气（直给、敢反驳、数据说话、给动作不给鸡汤）
六、规则与限制（数字三级纪律 / 显式假设 / 一次最多问 3 个问题 / 合规红线）
七、行业核心词（中英对照术语表）
八、行业违禁词与红线
九、输出格式（每个模式的固定结尾）
十、初始化（开场白：0→1 阶段先问成交沙盘进度）
十一、高频难题预案库（6 个标准应答预案）
十二、从 0 到 1 启动路线图（前 90 天，成交沙盘为第一优先级）
```

其中「预案库」是全篇最实用的部分——客户说太贵、已读不回、要赊销、被跳单比价、要验厂但没工厂、怎么判断供应商靠不靠谱，这六个场景直接调预案，不用每次从零分析。

## 4. 怎么用

**三步**：

1. 打开任意支持长上下文的模型（ChatGPT / Claude / Gemini / 本地模型均可）
2. 把 [`SKILL.md`](SKILL.md) 全文粘进「系统提示词 / 自定义指令 / Project Instructions」
3. 开始对话，用指令切模式：

```
/导师  客户说我的报价比别家高 15%，但他们比的是 FOB，我报的是 DDP，怎么谈？
/流程  客户要验厂，但我没有自有工厂，怎么处理？
/优化  这是我今天的待办：写完3封跟进邮件、查2家供应商、做1份报价单、更新网站
/信任  这个客户聊了两周，一直问价不下单
/机会  我这个月只有 8 个询盘，成交 0
```

**改造建议**：先把你自己的业务档案（第三节）填满，再开始用。空档案的提示词只能给出通用建议——这和没有提示词差别不大。

## 5. 一个真实输出节选

> **问**：我现在要开始我的外贸事业，第一步需要做什么？
>
> **答（节选）**：第一步不是建站，也不是投广告。是用 3 天、零成本，跑一次"成交沙盘"。
>
> 原因很直接：你卖的不是产品，是"我能帮你找到并安全送到"的确定性。这个确定性在你嘴里说顺之前，广告流量全是浪费——询盘来了你报不出有竞争力的到岸价，等于拿广告费练手。
>
> 沙盘四步：① 挑 1 个容易出询单的品类；② 找 3 家供应商报同一规格；③ 做一份真实报价单（出厂价 + 运费 + 验货 + 你的利润 = 到岸全包价）；④ 写一版真实英文报价邮件，发出去。
>
> 验收标准：**你能在 30 分钟内，对一个典型金额的询单报出到岸全包价、交期、验货方案。** 做到了再去建站投广告；做不到，先别花钱。
>
> 现在先别碰的三件事：五页精美官网、社媒四个平台同时铺、印名片画册。这三件是一人公司最典型的"看起来很努力、实际不产钱"的动作。

这个回答体现的是提示词里写死的三条规则：**先给结论**、**给动作不给方向**、**明确说什么别做**。

## 6. 质量迭代：两轮对抗审查，28 项修订

这个提示词经过**两轮独立 AI 对抗审查**（把成品交给另一个模型专挑毛病，逐条分类修复）。这一节记录了审查发现的典型问题类型和修复方法——比成品本身更有参考价值，因为它们是提示词工程的通用坑：

| 问题类型 | 审查发现的实例 | 修复方法 |
|---|---|---|
| **编造履历** | "深耕 15 年、年销数千万美金"会诱导模型虚构配套案例 | 删数字，改为能力边界声明 + 明令禁止第一人称虚构经历 |
| **数字无证据等级** | 验货费、办证周期等外部事实和汇率缓冲等策略参数混用同一口径 | **数字三级纪律**：外部事实给区间+核实途径；策略参数直给；他人战绩禁精确百分比 |
| **免责式标注** | "约 150-300 美金（需核实）"——先给数再补免责等于不负责 | 统一句式：先说不确定 → 再给区间 → 再给核实途径 |
| **规则自相矛盾** | 广告门槛写"12 小时回复"、流程标准写"2 小时回复"；0 客户却要求"真人评价" | 合并为一个标准（目标 2h/底线 12h）；0 客户期明确禁虚构、用实拍占位 |
| **路由误判** | 自动判断把"这单能不能做"（决策题）路由到核算模式 | 拆分"算"与"决策"，明文规定带金额不等于核算问题 |
| **无数据的算账** | 0 客户时 `/机会` 仍要求"基于你的转化率推算" | 零数据分支：禁止假装算账，改为输出"最该验证的 3 个假设" |
| **策略无退出条件** | "获客策略已定不得推翻"写死了，数据证伪了也改不了 | 增加证伪出口：数据证明失效时 AI 必须显式提修改建议，用户决策后才更新 |
| **合规凭记忆** | "不碰受制裁地区"但没说怎么判定 | 强制按官方名单核实（商务部/联合国/OFAC），禁止模型当场下结论 |

完整修订记录见 [`SKILL.md` 文末](SKILL.md#修订记录公开版)。

**教训**：两轮审查共 28 项，其中 7 项是**上一轮修复引入的新问题**（比如加优先级路由反而把决策题路由错了）。提示词和代码一样：修复本身需要回归测试，改完 ≠ 改对了。

## 7. 设计取舍

| 取舍 | 选择 | 原因 |
|---|---|---|
| 长度 | 1.2 万字，不压缩 | 工作流、判据、预案都需要具体文字承载；压缩后只剩口号 |
| 通用性 | 业务信息全部槽位化 | 公开版不能带真实商业参数，槽位化后反而更可复用 |
| 硬度 | 允许 AI 反驳用户 | "看你自己"是提示词最常见的失职 |
| 数据 | 数字按三类分级标注 | 外贸场景里编错一个退税口径，代价是真金白银 |
| 结构 | 模式而非功能清单 | 用户不会记得 30 个功能，但会记得 5 个指令 |
| 诚实 | 承认尚未被真实使用验证 | 所有"有效"目前是设计推理，不是实验结果——跑过真实询盘前的自我评分都不可信 |
